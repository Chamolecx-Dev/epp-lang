# 🚀 E++ (Español++)

Welcome to E++! A programming language created in Spanish, designed especially for beginners and to facilitate 2D game development.

This project uses a custom interpreter written in Python and features an integrated graphics engine based on Pygame.

## ✨ Key Features
* **Spanish syntax:** Easy to read and understand (e.g., `di: "Hola Mundo"`).
* **Dynamic typing:** Simple and straightforward variable handling.
* **2D graphics engine:** Create windows and entities, and handle collisions without complex configurations.
* **Interactive mode (REPL):** Write and test code line-by-line in the terminal.

## 🛠️ Requirements
* Python 3.8 or higher.
* Pygame (`pip install pygame`).
