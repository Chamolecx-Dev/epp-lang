# 🚀 E++ (Español++)

¡Bienvenido a E++! Un lenguaje de programación creado en español, diseñado especialmente para principiantes y para facilitar la creación de videojuegos 2D. 

Este proyecto utiliza un intérprete propio escrito en Python y cuenta con un motor gráfico integrado basado en Pygame.

## ✨ Características principales
* **Sintaxis en español:** Fácil de leer y entender (ej. `di: "Hola Mundo"`).
* **Tipado dinámico:** Manejo de variables sencillo y directo.
* **Motor gráfico 2D:** Crea ventanas, entidades y maneja colisiones sin configuraciones complejas.
* **Modo interactivo (REPL):** Escribe y prueba código línea por línea en la terminal.

## 🛠️ Requisitos
* Python 3.8 o superior.
* Pygame (`pip install pygame`).
